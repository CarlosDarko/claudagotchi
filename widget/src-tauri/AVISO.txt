CLAUDAGOTCHI - Antes de instalar / Before installing

QUÉ CAMBIA EN TU ORDENADOR
- Instala la mascota de escritorio en tu carpeta de usuario.
- La primera vez que arranca: se pone a arrancar con el ordenador, activa los avisos de Claude Code (hooks Notification y Stop en ~/.claude/settings.json, sin tocar los tuyos) y añade el comando 'claudagotchi' a tu terminal.
- Todo se puede quitar desde su icono junto al reloj o en la pestaña ⚙. Para desinstalar: Configuración → Aplicaciones → Claudagotchi, y 'claudagotchi desinstalar' para quitar los avisos.

PRIVACIDAD
- Sin telemetría ni servidores propios. Tus datos se quedan en ~/.claudagotchi.
- Se conecta solo a: Anthropic (tu % de uso, con tu sesión de Claude), GitHub (versiones nuevas) y Open-Meteo (el tiempo, solo si pones una ciudad). Cada conexión se apaga en ⚙.
- Política completa: https://github.com/CarlosDarko/claudagotchi/blob/main/docs/privacidad.md

WHAT CHANGES / PRIVACY (English)
On first run it starts with your computer, enables Claude Code hooks and adds the 'claudagotchi' command to your PATH. All can be turned off. No telemetry. It only contacts Anthropic (your usage %), GitHub (updates) and Open-Meteo (weather, only if you set a city); each can be disabled in the ⚙ tab.
